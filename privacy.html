Privacy Policy

Last updated: 30 October 2026

This policy explains what data the Gel Pisi Pisy website and publishing tool (the "Service") handle.

Visitors of this website

The website is a static page hosted on GitHub Pages. We do not use cookies, analytics or tracking. GitHub may log technical data such as IP addresses for security; see GitHub's privacy statement.

Data the publishing tool uses

The tool signs in only to accounts owned by Gel Pisi Pisy. From TikTok it receives an access token, a refresh token, the account's open ID, username and display name, and the posting options of that account (allowed privacy levels, comment/duet/stitch settings, maximum video length). From YouTube and Instagram it receives the equivalent tokens and channel or account IDs.

How it is used and stored

This data is used only to upload our own videos and to check the result. Tokens are stored on our own computer in a file that only our user account can read; they are never shared, sold or sent to anyone other than the platform they belong to. We do not collect data about other TikTok, YouTube or Instagram users.

Retention and deletion

Tokens are kept while the tool is in use and deleted when access is revoked. Access can be revoked at any time in the platform's settings (for TikTok: Settings and privacy → Security and permissions → Apps and services permissions).

Changes

We may update this policy; the date above shows the latest version.
